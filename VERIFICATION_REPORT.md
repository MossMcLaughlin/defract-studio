## Build and automated tests

Color-engine Checkpoint 3 completed on 2026-11-03. New imports use schema/renderer v3; saved v1 and transitional v2 projects continue through the unchanged legacy math. Fixed RGBA8 pixel references from saved v1/v2 recipes passed after the upgrade. Renderer v3 adds linear `2^EV` exposure, direction-tested native temperature/tint, a monotone 4096-sample luminance tone curve, continuous eight-band Oklab mixer, perceptual saturation/vibrance, alpha-safe processing, and a fixed-hue SDR gamut boundary. A recipe-keyed 1025-sample mixer table avoids per-frame Gaussian band evaluation. Easy mapping, masks, geometry, and export processing were not changed.

The final Xcode build passed and the final full suite passed **41 tests, 0 failures, 0 skips**. Focused tests checked v1/v2 saved color pixels, neutral identity, +1 EV, positive warm/magenta directions, extreme monotone tone output, all 24 mixer Hue/Saturation/Luminance controls, green/aqua hue directions, hue wrap, saturation/vibrance direction, gray and transparent edges, finite extended values, and global plus local mask composition. No GUI color-quality evaluation was performed, so artistic quality on diverse scenes remains for human review.

Performance smoke on this Mac showed `testMain10PortraitVideoGradeAndExport` increasing from **2.185 s** (pre-upgrade) to **4.114 s**, `testOpposingGoProRotationsExportUpright` from **16.025 s** to **27.003 s**, and `testVideoFitAndFillMatchPreviewAtExactSize` from **2.737 s** to **5.315 s**. These whole-test durations include decode, export and assertions, so they are not isolated kernel timings, but they show a roughly **1.7–1.9×** video-path regression. Live playback frame rate and peak memory were not measured; the dedicated performance checkpoint should profile them before any 30 fps claim. A baseline run first failed only when Vision could not open an OS model blob (`ANECF` I/O error); the focused Vision rerun and subsequent full suites passed. Xcode's Metal Toolchain component had to be installed to compile the new shader.

HDR/Log normalization, noise protection, dehazing, export precision changes and macOS 15 runtime testing remain outside this checkpoint. Video metadata is probed asynchronously; unsupported HDR is blocked once its transfer is identified.
