# Development notes

Gate 0 establishes a macOS 15 compatible rendering path. `EditorCore/Core.swift` owns the Core Image grade, and `EditorApp/MediaIO.swift` adapts still images and AVFoundation frames to that same function. The AVFoundation handler is `AVVideoComposition.videoComposition(with:applyingCIFiltersWithHandler:completionHandler:)`, available on macOS 15; the macOS 26 only initializer is not used. Export first writes a sibling temporary file and moves it into place after success.

Gate 1 added `EditorCore/Recipe.swift` for the versioned Easy base, Advanced delta and saved effective state; `ColorMath.swift` for all global color controls; `Geometry.swift` for source-relative aspect crops; and `ProjectStore.swift` for atomic JSON saves and bounded undo history. The Easy knots match `COLOR_ENGINE.md` v1. The HSL mixer uses overlapping smooth hue weights; positive Green and Aqua Hue move toward blue. The 33³ Core Image color cube maps linear RGB through exposure, smooth tone controls and encoded HSL, and is cached by adjustment values. Temperature/tint use Core Image's temperature-and-tint filter. These formulas are provisional photographic choices, not Lightroom parity. `EditorTests` currently compiles `MediaIO.swift` directly to test the platform adapter without a GUI test host. The shared core never imports AppKit.

`EditorApp/EditorModel.swift` owns autosaved selection and edit transactions; `App.swift` owns the workspace views. Drag updates use a draft recipe, then commit one undo transaction on gesture end. Photo previews decode to a maximum 1800-pixel thumbnail on a background task; decoded thumbnails are cached and disposable. The full-resolution original is reopened only for export.

Gate 2 added `Masks.swift` for normalized radial, linear, brush and Vision matte data. Each enabled local grade runs on the current graded frame, then blends by its alpha; order is saved order. `VisionMask.swift` stores Apple's foreground matte as PNG in the recipe, while brush Add/Erase strokes remain independent data and survive reload. The app offers subject and brush only for photos; video has radial and linear gradients. `CropOverlay.swift` and `GradientOverlay.swift` keep handles in source coordinates; `Geometry.swift` maps points through crop, straighten and quarter turns. `OutputFrame.swift` applies Fit padding or Fill crop after geometry, preserving aspect ratio. H.264 and HEVC export use the same macOS 15 compatible CI video-composition callback. Reader/Writer was unnecessary on tested fixtures.

The Xcode build uses an unsandboxed local Debug app, so source paths are stored directly; sandboxed distribution would need security-scoped bookmarks. The source media remains untouched. Preview caches, temporary exports, and all fixture files are outside source control.

The Xcode project has one app, one framework, and one test target. `EditorApp/App.swift` is the app entry point. Build artifacts belong outside the repository (the commands use `/private/tmp/defract-derived`). Private fixtures and generated exports are ignored by Git.

Gate 3 added `ExportOptions.swift` for the three preset dimensions, aspect choices, file naming and format validation; edit preset values there. `ExportSheet.swift` owns the native output dialog. The selected `OutputFrame` is temporarily applied to live preview, then saved with the recipe on export. `MediaIO.swift` writes to a sibling temporary file, verifies readable output and audio presence, and commits it only after success. An existing destination requires confirmation; cancellation and failed output remove the temporary file. `WindowCloseObserver.swift` provides the close and quit reminder through AppKit, since SwiftUI has no equivalent window-close veto. A corrupt project JSON file remains on disk while other sessions load; dates are saved at millisecond precision and older ISO8601 files still decode.

The dark workspace colors and control sizes are in `EditorApp/App.swift`; color formulas are in `EditorCore/ColorMath.swift` and Easy curve knots in `EditorCore/Recipe.swift`. Mask alpha and geometry live in `Masks.swift` and `Geometry.swift`. Output framing is in `OutputFrame.swift`. The project stores absolute source paths and file size for relinking; a moved source must be relinked manually. This local Debug app is not sandboxed for App Store distribution. Xcode test output is the authoritative automated verification; visual interaction and close-dialog behavior still need a human GUI pass on a visible desktop.
